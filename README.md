## What is Markdown?

Markdown is a lightweight markup language used to format plain text in a simple and readable way. It allows users to create headings, lists, links, tables, images, and code blocks without using complex formatting tools.

Markdown is commonly used on GitHub to create `README.md` files. These files help describe a project, explain its purpose, and provide useful information for other users or developers.

## Repository Objective

This repository was created as a practice activity for learning the basic use of Git, GitHub, and Markdown.

The main objectives are:

* Create a local Git project.
* Create a remote repository on GitHub.
* Write a simple `README.md` file using Markdown.
* Practice basic Git commands.
* Upload the project to GitHub using the command line.
